**现有API清单**:

5. **Config系统**: 配置管理
6. **Network API**: 网络通信

**验证方法**:
```java
// 每个API都应该有类似的回退逻辑
public static SomeApi getInstance() {
    try {
        // 尝试加载AprismJDK实现
        Class<?> implClass = Class.forName("aprism.agent.SomeApiImpl");
        return (SomeApi) implClass.getMethod("getInstance").invoke(null);
    } catch (Exception e) {
        // 回退到Stock实现
        return StockSomeApi.INSTANCE;
    }
}
```

**测试策略**:

## 三、实现计划

### 3.1 版本检测工具

创建工具类检测运行时Java版本：

```java
package jdk.aprismate.util;

public final class JavaVersion {
    private static final int VERSION = Runtime.version().feature();
    
    public static boolean isJava17OrHigher() {
        return VERSION >= 17;
    }
    
    public static boolean isJava21OrHigher() {
        return VERSION >= 21;
    }
    
    public static boolean isJava25OrHigher() {
        return VERSION >= 25;
    }
    
    public static int featureVersion() {
        return VERSION;
    }
}
```

### 3.2 Multi-Release JAR

为不同Java版本提供优化实现：

```
aprismate-api.jar
├── META-INF/
│   └── MANIFEST.MF (Multi-Release: true)
├── jdk/aprismate/...      # Java 17基线
├── META-INF/versions/21/
│   └── jdk/aprismate/...  # Java 21优化
└── META-INF/versions/25/
    └── jdk/aprismate/...  # Java 25优化
```

### 3.3 Stock JDK测试套件

创建专门的Stock JDK测试：

```java
@Test
public void testStockJdkFallback() {

    // Stock JDK应该返回安全默认值
    assertFalse(vmInfo.isAprismJDK());

}
```
